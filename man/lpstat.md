## DESCRIPTION

Show the printers and the print jobs. With no option, your own jobs not
yet printed.

## OPTIONS

- `-p`: the printers, and whether each is printing.
- `-d`: the default printer.
- `-o`: every job not yet printed: its id (`PRINTER-ID`), owner, state
  (pending, printing), time and title.
- `-v`: each printer's address.
- `-t`: all of the above.
