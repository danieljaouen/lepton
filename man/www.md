## DESCRIPTION

A text-mode web browser for the terminal. It fetches URL, shows the page
as text, and numbers its links. `lynx` and `browse` are the same
command. For the full web, use Firefox on the desktop (`firefox`).

## KEYS

- `j`, `Down`, `Ctrl-N`: down one line; `k`, `Up`, `Ctrl-P`: up one
  line.
- `Space`, `Ctrl-F`, `Page Down`: down one screen; `b`, `Ctrl-B`,
  `Page Up`: up one screen.
- A number then `Enter`: follow that link.
- `H`: go back.
- `g`: go to a URL you type.
- `q`, `Ctrl-C`: quit.
