## DESCRIPTION

Print the one-line summary of each NAME's manual page: a command, one
of its other names, or a shell builtin. `man -f NAME` is the same.

## EXIT STATUS

0 when every NAME has a page, 16 when one doesn't, 2 for a usage error.

## EXAMPLES

    whatis grep
    whatis ls cd

## SEE ALSO

man(1), apropos(1)
