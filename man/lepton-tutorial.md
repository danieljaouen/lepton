## DESCRIPTION

An interactive tour of Lepton in the terminal, one lesson at a time,
each with a command to try: files, pipes and text tools, jobs and
processes, services, the editor, tmux, git and GitHub, packages, the
network and where to find help. `tutorial` is the same command. It is
offered on the first boot of an installed system.
