## DESCRIPTION

Print information about the system. With no option, print the kernel
name (`Linux`).

## OPTIONS

- `-a`: all of the below.
- `-s`: the kernel name.
- `-n`: the host name.
- `-r`: the kernel release.
- `-v`: the Lepton version, with its Elixir and OTP versions.
- `-m`: the machine architecture (`aarch64`).
- `-o`: the operating system (`Lepton`).
