## DESCRIPTION

Start the classic desktop: Photon with a window manager styled after
Windows 95. It has grey window frames with minimize, maximize and close
buttons; desktop icons for Firefox, the Terminal, the Text Editor, the
System Monitor and each mounted USB drive or SD card; a taskbar with a
button for each window, the Wi-Fi signal, Bluetooth, the volume and a
clock; and the Start menu (click Start or press Ctrl+Esc).

The keys of `photon` work here too. Exit Desktop in the Start menu, or
Ctrl+Alt+Backspace, returns to the console.
